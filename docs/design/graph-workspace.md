# Scientific constellation

The Graph stage uses a full viewport Sigma 4.0.3 canvas below the existing navigation. The canvas matches the application’s ice silver #DDE3E8 shell, with aubergine #3A0F34 labels. Richer semantic node colors use amber #B77A08, teal #287F8C, muted violet #79609C and slate #657786; node sizes preserve the existing hierarchy. Panels use the application’s light paper surface. Zoom in, zoom out and fit sit at bottom-right; a collapsed Filters control sits above the bottom-left interaction hint. Right-click, E or / opens contextual search and evidence inspection. Every loaded node is rendered by default; explicit filters never alter the complete evidence model.

Filters use multi-select checkbox groups for node types and evidence classes, with repository and relationship groups nested beneath them. Options and counts come from the complete loaded snapshot, not the filtered projection. Reset filters preserves camera, positions and inspection. Filtering never restarts physics or refits the camera.

## Rendering fixes

Sigma 4 requires explicit x/y attribute bindings to enable dragging. Node sizes use screen pixels, rather than graph units, so a normalized layout cannot produce oversized spheres. Container ResizeObserver handling and measured viewport bounds fit nodes and labels after initialization and on resize.

The graph stage reserves at least 240px of height and keeps the header from shrinking. Short viewports scroll rather than collapsing Sigma's container to zero; `allowInvalidContainer` remains disabled. Camera restoration only measures labels for nodes already present in Graphology, so returning to the tab cannot read coordinates before graph population.

Sigma's dashed layer returns transparent for zero-gap edges: it expects a plain layer underneath. The pinned renderer's single-layer variant returns the edge color for that branch. Its dash and gap variables are declared explicitly so per-edge inferred/unverified patterns reach the GPU. Documented edges are solid cool gray-purple; returned inferred edges are dashed muted violet; unverified possibilities are dotted. Hover and selection brighten incident relationships. No new semantic edges are generated by the renderer.

Labels use a permanent DOM overlay synchronized with Sigma coordinates. Every rendered node retains its label at every zoom level. Labels switch sides near viewport edges and use bounded local offsets to reduce collisions, without changing graph coordinates or suppressing crowded labels. This avoids Sigma 4.0.3's discarded picking-label fragment output producing WebGL warnings on Chrome. The supported `nodeLabelEvents: "extend"` setting is configured; because GPU labels remain disabled, DOM buttons mirror node hover, activation, selection and focus. Node hover changes only graph emphasis, with no duplicate tooltip or browser title. Keyboard focus highlights the same neighborhood; Enter/Space opens inspection. Wheel events over labels reach Sigma zoom. Native WebGL node/edge picking and dragging remain enabled.

Edge hover shows the returned relationship type and evidence class. Click opens the compact inspector at the edge midpoint, with source/target labels, provenance, raw verification status and supplied supporting evidence. Missing evidence is explicitly unavailable. The keyboard-accessible evidence list and node relation lists open the same inspector, so relationship information never depends on hover alone.

## Layout lifecycle

The deterministic initial seed feeds a simplified ForceAtlas2 worker graph, with one layout edge per pair and size-aware collision spacing. Strong gravity bounds weakly connected nodes. Initial computation happens offscreen for up to 1.2 seconds and publishes once. The camera fits before reveal; there is no recurring simulation. Existing positions survive tab navigation, dragging, and filters; relationship-only snapshots do not restart physics. All scientific parallel relationships remain in Graphology and the evidence list.

The actual Sigma interaction layer uses grab, grabbing and pointer cursors, including pointer release outside the graph. Reduced motion disables camera animation. The graph's central halo is static.

## Evidence rules

Discovery determines dataset membership. Variable identities contain the dataset ID and exact column name. Ambiguous normalized matches remain warnings, not fabricated exact mappings. Cached provenance stays labeled; metadata similarity is never presented as suitability or verified joinability. Source verification times remain unavailable unless supplied. Analysis responses are accepted only for the matching question generation and dataset.

## Validation

Frontend: production TypeScript/Vite build and Vitest suite. Renderer tests verify every loaded node and edge, valid endpoints, coordinate bindings, screen-space sizes, and zero-gap solid fallback. Worker tests verify offscreen publication, size-aware settings, deadline and teardown.

Chrome browser checks at 1440×900 and 390×844 confirmed the cached fixture's 16 nodes and 18 edges, valid endpoints, visible lines, neighborhood emphasis, source inspection, drag/pan/zoom, pointer cursors, fitted bounds and stable idle positions. No browser warnings or errors were observed in the final pass. Performance on physical mobile hardware has not been benchmarked.
