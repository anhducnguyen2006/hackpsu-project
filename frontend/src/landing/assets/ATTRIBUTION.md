# DataOPedia scientific panel assets

These photographs illustrate scientific ways of seeing. They are not DataOPedia datasets, results, partnerships, or endorsements. Photographs are cropped by CSS for display. The interactive panels retain their existing treatment. Downloads are hosted locally; no third-party image requests are made by the page.

The interactive scientific panels use these files, with CSS crops and contrast overlays. The circular arrow links open the original source pages. Credits are displayed on each panel; image files are unmodified.
